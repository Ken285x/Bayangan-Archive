# Bayangan Archive – Functional Audit

Date: 17 September 2026

## Checked in this package
- 57 PHP files passed `php -l` syntax validation.
- Shared JavaScript (`assets/app.js`) passed `node --check`.
- Inline game JavaScript was reviewed for DOM element references and syntax.
- Shared header/footer structure was checked and the malformed `</aside>v><main>` markup was corrected.
- Game API routes were checked: `api/save_game.php`, `api/use_hint.php`, and `api/interactive_event.php`.
- Database-driven game tables and CMS fields were checked against the SQL definitions.
- Upload preview behavior remains enabled globally for image/video file inputs.

## Functional fixes in this package
1. Jigsaw countdown now runs `3 → 2 → 1 → GO!` before enabling play.
2. Jigsaw boards are generated by legal moves from the solved state, preventing unsolvable random boards.
3. Jigsaw completion is guarded against duplicate saves.
4. Jigsaw hint highlighting is improved when the blank space is already in the final slot.
5. Quiz and identification points now follow Easy/Medium/Hard values instead of always using 10 points.
6. Matching points now follow Easy/Medium/Hard values instead of always using 10 points.
7. Arrange-the-Steps points now follow Easy/Medium/Hard values instead of always using 15 points.
8. Shared navigation HTML was corrected.
9. Removed a duplicate no-op initialization check in shared JavaScript.
