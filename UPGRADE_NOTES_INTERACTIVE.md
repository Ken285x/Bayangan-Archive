# Bayangan Archive — Interactive Heritage Upgrade

This build adds the requested dynamic and interactive features while intentionally excluding the 3D viewer and AI assistant.

## Added
- Interactive Heritage Lab (`interactive.php`)
- Heritage Quest missions with browser-local XP, levels, and badges
- Interactive pot-making process explorer
- Choice-based pot-making simulator
- Traditional Terminology Challenge
- Pronunciation practice: listen, record, replay; no automatic pronunciation scoring
- Traditional terminology English/Filipino fields, photo, and verification status
- Knowledge Explorer search
- Visual Knowledge Map
- Artisan Story / Ask the Artisan presentation with optional voice recording
- Knowledge of the Day / Daily Challenge
- User feedback collection
- Anonymous interaction-event analytics
- Admin Interactive Experience CMS for process steps, quests, and artisan stories
- Backup support for the new tables
- Compact UI rules and smaller buttons

## Important fieldwork rule
Starter/demo process and quest records are placeholders for testing the interface. Replace or verify them using actual fieldwork, interviews, observations, photographs, videos, and approved sources before final defense/public deployment.

## Browser requirements
- Audio recording and pronunciation features require microphone permission.
- Microphone access for audio features normally works on localhost in XAMPP.
- Pronunciation practice remains in the browser and is not uploaded.
- Traditional Terminology recordings created in the Admin CMS are uploaded to `uploads/audio/`.
